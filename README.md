# Studio Code Arcade

MVP 0 — milestone 1: apresentação visual do desafio.

## Abrir

Extraia o pacote e abra `public/index.html` no navegador. Não requer servidor, banco, instalação ou conexão à internet. Em celular/tablet, a interface adapta-se à largura disponível.

## Entregue

- Grid 5 × 3, quatro obstáculos e objetivo.
- BOT-001 na posição inicial, orientado para leste.
- Dados do desafio separados da apresentação.
- Legenda e descrição textual acessível do tabuleiro.

Este marco ainda não executa comandos. A seta no robô indica orientação e não é um botão de controle remoto.

## Próximos milestones aprovados

2. Editor para adicionar, reorganizar e remover comandos.
3. Confirmação, validação PHP, persistência MySQL e carregamento.
4. Execução visual, destaque dos comandos e resultado.
5. Nova tentativa e revisão em celular/tablet.

PHP/MySQL permanecem na arquitetura. A página HTML permite testar o primeiro marco antes da instalação do backend.
